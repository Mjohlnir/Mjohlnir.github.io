# Atlas · site público

Site: https://mjohlnir.github.io/

Hospedagem pelo GitHub Pages. Código de desenvolvimento no repositório privado `Mjohlnir/Atlas`. Este repositório contém apenas a aplicação estática e sua configuração **publicável** Supabase.

O acesso pelo Google ainda depende da ativação do provedor OAuth e da lista de e-mails autorizados com o hook Before User Created no Supabase. Não ative cadastros públicos antes do hook. Não envie chaves secretas, bibliotecas, históricos ou arquivos pessoais.

Este é um protótipo inicial reduzido; a paridade de funções com a v21 ainda está pendente.
